## Sobre mí

Me interesa el **desarrollo de software**, el **desarrollo web**, las **bases de datos** y la **inteligencia artificial**. Disfruto aprender nuevas herramientas y convertir ideas en soluciones útiles, accesibles y bien pensadas.

Actualmente trabajo en **SIeR — Sistema Integral de Registros**, un sistema para gestionar información y procesos del departamento de Orientación de una institución educativa.

> Cada proyecto me enseña algo nuevo; cada línea de código me acerca a la desarrolladora que quiero ser.
